# Bearagnostic — Privacy Policy

**Privacy version:** 1.0.0  
**Effective / updated:** 11 September 2026

## English

Bearagnostic is designed as a local-first Android file-health assistant.

### File analysis

File metadata, supported local previews, duplicate verification, review state, and cleanup decisions are processed on the device within Android access boundaries. The current Bearagnostic app does not upload selected file contents and does not maintain a remote inventory of filenames or file paths.

### Local history

Bearagnostic may store bounded aggregate checkup and verified-cleanup history locally on the device for Insights. The history is designed to exclude filenames, file paths, file contents, review IDs, and persistent file hashes. Users can clear local Insights history from the app.

### Google Play Billing

When Google Play Billing is used, Google Play may process purchase, account, product, payment, and entitlement-related information under Google's own terms and privacy practices. Bearagnostic uses billing state needed to offer, purchase, restore, acknowledge, and maintain Pro entitlement. The WebView UI should not receive raw purchase tokens, order IDs, or raw purchase JSON merely for presentation.

### Network use

Normal file analysis does not require uploading selected files. Network access may occur for Google Play Billing or when the user deliberately opens a support link or other clearly disclosed external action.

### No behavioural advertising

Bearagnostic does not intentionally add behavioural advertising, hidden file-content telemetry, or a remote filename inventory as part of the current product model.

Privacy claims must continue to match the actual implementation. Any future change that materially changes data handling should update this policy before release.

## ภาษาไทย

Bearagnostic ออกแบบเป็นผู้ช่วยดูแล File Health บน Android แบบ local-first

### การวิเคราะห์ไฟล์

Metadata ของไฟล์ preview บนเครื่องที่รองรับ การยืนยันไฟล์ซ้ำ สถานะ review และการตัดสินใจลบ ถูกประมวลผลบนอุปกรณ์ภายในขอบเขตที่ Android อนุญาต เวอร์ชันปัจจุบันของ Bearagnostic ไม่อัปโหลดเนื้อหาไฟล์ที่ผู้ใช้เลือก และไม่เก็บคลังชื่อไฟล์หรือพาธของไฟล์ไว้บนระบบระยะไกล

### ประวัติบนเครื่อง

Bearagnostic อาจเก็บประวัติ Checkup และการลบที่ยืนยันแล้วในรูปแบบข้อมูลสรุปและมีขอบเขตจำกัดไว้บนอุปกรณ์เพื่อใช้กับ Insights ประวัตินี้ออกแบบให้ไม่เก็บชื่อไฟล์ พาธ เนื้อหาไฟล์ review ID หรือ file hash ระยะยาว ผู้ใช้สามารถล้างประวัติ Insights บนเครื่องได้จากแอป

### Google Play Billing

เมื่อใช้ Google Play Billing ทาง Google Play อาจประมวลผลข้อมูลที่เกี่ยวกับการซื้อ บัญชี สินค้า การชำระเงิน และ entitlement ภายใต้เงื่อนไขและแนวทางความเป็นส่วนตัวของ Google เอง Bearagnostic ใช้สถานะ Billing เท่าที่จำเป็นต่อการแสดงสินค้า ซื้อ กู้คืน acknowledge และรักษาสิทธิ์ Pro โดย WebView ไม่ควรได้รับ raw purchase token, order ID หรือ raw purchase JSON เพียงเพื่อใช้แสดงผล

### การใช้อินเทอร์เน็ต

การวิเคราะห์ไฟล์ตามปกติไม่ต้องอัปโหลดไฟล์ที่เลือก การใช้อินเทอร์เน็ตอาจเกิดขึ้นกับ Google Play Billing หรือเมื่อผู้ใช้ตั้งใจเปิดลิงก์ช่วยเหลือหรือการทำงานภายนอกที่แจ้งไว้ชัดเจน

### ไม่มีโฆษณาเชิงพฤติกรรม

โมเดลผลิตภัณฑ์ปัจจุบันของ Bearagnostic ไม่ได้ตั้งใจเพิ่ม behavioural advertising, telemetry ลับที่ส่งเนื้อหาไฟล์ หรือคลังชื่อไฟล์ระยะไกล

คำอธิบายด้านความเป็นส่วนตัวต้องตรงกับ implementation จริงเสมอ หากในอนาคตมีการเปลี่ยนวิธีจัดการข้อมูลอย่างมีนัยสำคัญ ต้องอัปเดตนโยบายนี้ก่อนเผยแพร่
